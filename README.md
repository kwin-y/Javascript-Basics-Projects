## THE ODIN PROJECT - JAVASCRIPT BASICS
Name and Section: Rollorata, K - CKDELM1

This repository combines three assignment projects into a single organized workspace.

- Rock Paper Scissors Game - played entirely in the console
- Etch A Sketch - browser version of something between a sketchpad and an Etch-A-Sketch
- Calculator - browser on-screen calculator

Each file contains necessary JavaScript, HTML, and CSS.

## HOW TO RUN EACH PROJECT
- Rock Paper Scissors:
    - Make sure index.html and script.js are in the same folder.
    - Open index.html in a web browser (double-click the file, or right click -> Open with -> your browser).
    - Hit Ctrl + Shift + I (or right click any surface of the open file -> inspect -> console) before filling in what's asked
    - To run again, refresh the page.

- Etch A Sketch:
    - Make sure index.html, script.js, and style.css are in the same folder.
    - Open index.html in a web browser (double-click the file, or right click -> Open with -> your browser).
    - Hover your cursor through boxes
    - Try Changing the Grid Sizes
    - To run again, refresh the page.

- Calculator:
    - Make sure index.html, script.js, and style.css are in the same folder.
    - Open index.html in a web browser (double-click the file, or right click -> Open with -> your browser).
    - Use it like a typical Basic Calculator
